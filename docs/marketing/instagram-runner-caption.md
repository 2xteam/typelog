## 만들어 둔 공유 링크는 어디에 쓰나

`/r/<토큰>` 링크는 **로그인 없이 바로 풀 수 있는 유일한 주소**다. 그래서 쓸 자리가
따로 있다.

| 자리 | 되나 | 메모 |
|---|---|---|
| 피드 게시글 **본문** | ❌ | 인스타그램 본문의 링크는 눌리지 않는다. 그래서 지침이 프로필 링크로 보낸다 |
| **스토리 링크 스티커** | ✅ | 여기서는 눌린다. 공유 링크를 그대로 넣으면 로그인 없이 바로 풀 수 있다 |
| DM · 카카오톡 | ✅ | 미리보기 이미지가 함께 뜬다 → `app/r/[token]/opengraph-image.tsx` |
| 프로필 링크(`www.myjane.co.kr/link`) | ✅ | TypeLog 를 맨 위로 올려 뒀다 |

> ⚠️ **공유 링크는 운영자 본인의 응시 1건에 붙어 있다.** 열면 `A FRIEND SHARED`
> 아래에 그 결과가 보인다. 친구에게 보내는 용도로 만든 것이라 공개 게시물에
> 오래 걸어 두는 것과는 성격이 조금 다르다 — 스토리(24시간)에는 잘 맞는다.

### 남은 구멍 — 질문지 하나로 바로 가는 공개 주소가 없다

지금 로그인 없이 열리는 경로는 `/`(소개) 와 `/r/[token]`(개인 공유 링크) 뿐이다.
`/types` 는 로그인이 필요하다. 그래서 프로필 링크로 들어온 사람은
소개 페이지 → 로그인 을 거쳐야 러너 질문지에 닿는다.

`/q/[slug]` 같은 **공개 진입 페이지**가 있으면 이 글의 전환이 훨씬 나아진다
(게스트 응시를 바로 시작 · 질문지당 1회 제한은 그대로). 필요하면 만든다.

  질문지 자체의 안내 문구와 같은 말이다
